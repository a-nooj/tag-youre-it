# Contributing

Thanks for considering a contribution to Tag, You're It!

## Local setup

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static output in dist/
```

## Making changes

- Fork the repo and open a pull request from a branch off `master`.
- Keep PRs focused — one change per PR is easier to review.
- For anything bigger than a small fix (new marker type, major refactor, etc.), please open an issue first to discuss the approach before writing code.

## Bugs and ideas

Open a GitHub issue. Include steps to reproduce for bugs, or a short description of the use case for feature requests.
